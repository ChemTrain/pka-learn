# pKa Learn

A Quizlet-style quiz for learning the pKa values of organic acids and bases. Everything is in one HTML file.

**Play it here:** https://quentinbind.github.io/pka-quiz/pka_quiz.html

You can also download `pka_quiz.html` and open it in any browser.

## What's inside

- 253 cards in seven sets: textbook essentials, enolates, carbanions and ylides, O–H acids, amines, N–H acids, and bases for synthesis
- A 2D structure for each molecule, with the acidic proton highlighted
- A Learn mode (multiple choice, then typed answers), flashcards, and space for your own cards or a Quizlet export
- Rank: deal 5, 10 or 15 cards from a set and put them in order, lowest pKa first
- Most acidic: 29 molecules with two to four labelled protons; pick the most acidic one, then see the pKa of each

## Sources

Most values come from the [Evans pKa table](https://organicchemistrydata.org/hansreich/resources/pka/pka_data/evans_pKa_table.pdf) (D. H. Ripin and D. A. Evans, ACS Organic Division, updated 2024). The textbook set uses common textbook values. Structures are drawn with [RDKit](https://www.rdkit.org).
